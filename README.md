## 🌱 Why This Project Exists

Wuchang: Fallen Feathers is a game built on atmosphere, timing, and deliberate decision-making. Every battle is a conversation; every death is a lesson. A traditional companion utility — the kind that blinks in and out of your overlay like a nervous firefly — actively fights against that atmosphere.

This repository takes a different stance. Instead of overlaying, it **integrates peripherally**. It lives in a side window, a second monitor, or a compact panel. It observes, summarizes, and organizes. It never spoils. It never rushes. It never tells you that you "should" be doing anything different.

The project was born in the community, shaped by the observation that **many players simply want better bookkeeping** for their journeys — not a magic wand. And so, we built it.

## 🎨 The Progression Canvas

The **Progression Canvas** is the heart of the companion. It is a spatial metaphor: instead of a linear list of tasks, your journey is expressed as a landscape. Distant mountains represent long-term goals; nearby stones represent immediate opportunities; scattered lanterns mark memorable moments you have chosen to preserve.

Players frequently describe the Canvas as a "scrapbook that rewrites itself." Over a 2026 season, your Canvas fills with cartography — tiny personal landmarks that only you can interpret. Nothing is decided for you. Nothing is auto-completed. The Canvas is quiet until you invite it to speak.

## 📱 Responsive & Adaptive UI

Modern Windows machines come in every shape: 4K monitors, tiny laptops, ultrawide screens, tablets with detachable keyboards. A companion that assumes one form factor is a companion that fails on all the others.

Our interface is built on a fluid layout engine that:

1. Reflows column counts as the window narrows.
2. Increases type size on high-DPI displays without blurring.
3. Recolors accents based on the host system's accessibility palette.
4. Supports keyboard-only navigation for every action.
5. Honors **Reduced Motion** preferences at the operating system level.
6. Provides a compact "pill" mode for narrow side panels.

The guiding metaphor is water: the UI takes the shape of its container, but never loses its character.

## 🚀 Performance & Footprint

Performance is a feature, not an accounting line. The companion is engineered to disappear when it is not needed and reappear instantly when it is.

- Cold start is measured in a fraction of a second on typical 2026 hardware.
- Idle memory hovers in the low double-digit megabytes.
- Background CPU utilization drops to near-zero when no session is active.
- Disk writes are batched to minimize SSD churn.
- Log rotation is automatic and non-destructive.

If you notice a regression, please open a performance report. We treat slow startups as bugs of the highest priority.

## ⚙️ Configuration Overview

The companion is configured through a single, human-readable file located in the application data directory. Editing it is entirely optional — the defaults are sensible — but power users will find many knobs to turn.

Representative configuration topics include:

- **Interface density** — compact, comfortable, or spacious.
- **Language preference** — override the system locale if desired.
- **Session journaling scope** — what to record and what to leave out.
- **Privacy controls** — what may be logged locally, and nothing beyond.
- **Accessibility flags** — high contrast, reduced motion, larger cursors.
- **Update channel** — stable, preview, or frozen snapshot.

Every option is documented in the in-app help panel, and every default has been chosen to respect the player, not to harvest data.
